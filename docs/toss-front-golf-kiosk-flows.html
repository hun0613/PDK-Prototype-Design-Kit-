#화면핵심 요소토스프론트 → 엘커넥트 API비고
01메인화면「도착 인증」 / 가맹점 기준 로그인 기능가맹점 로그인진입점. 키오스크는 가맹점(매장) 단위로 인증
02인증 방법 선택「QR 스캔」 / 「얼굴 인증」 버튼 2개—사용자 선택에 따라 03A / 03B로 분기
03AQR 스캔• 토스프론트가 약속된 규약대로 QR 페이로드 자체 생성·표출
   페이로드: 가맹점 정보 · 단말기 정보 · 유효시간(TTL) · 유니크한 키값(nonce) · 시그니처(HMAC-SHA256)
• 사용자가 엘커넥트 앱으로 스캔 → 엘커넥트 앱이 인증 결과를 토스 내부 서버로 송신(성공/실패 + 회원 정보)
• 토스프론트가 토스 내부 서버에 nonce로 폴링
• 수신받은 회원 정보로 "가능 예약 리스트" 호출		(엘커넥트 직접 호출 없음)
폴링: 토스 내부 서버
03B얼굴 인증• 카메라 활성화
• 사용자가 얼굴 센터에 맞추고 「인증하기」 클릭
• 엘커넥트에 사진 데이터 전송 (가맹점·단말기 정보 포함)
• 성공/실패 + 회원 수신
• 수신받은 회원 정보로 "가능 예약 리스트" 호출		얼굴 인증 (사진 전송)우선 버튼식(자동 인식 X). 1:N 매칭으로 회원 식별
05도착인증 완료인증 가능 예약 리스트 (기간제 / 시작·종료 시간) → 클릭 → 「인증 완료」 뱃지 → 「홈으로 돌아가기 →」도착인증 가능 예약 목록
도착인증 완료 처리		예약 없으면 「도착인증 가능한 예약이 없습니다」 팝업

#화면핵심 요소토스프론트 → 엘커넥트 API비고
1메인화면「1회권 구매」 카드 결제 / 가맹점 기준 로그인 기능가맹점 로그인진입점. 키오스크는 가맹점(매장) 단위로 인증
21회권 상품 선택 (default)상품 카드 리스트 (예: 60분 1,100원 / 300분 1,200원 / 90분 50,000원)상품 목록키오스크 판매 ON 상품만 응답
31회권 상품 선택 (selected)선택된 상품 강조 + 수량 변경 UI(−/+) 노출, 기본 수량 = 1—상품 1개 선택 시 수량 기본값 1
4휴대전화번호 입력 (Optional)숫자 키패드, 010 prefix 고정, 「지우기 / 확인」—미입력으로도 진행 가능
5타석 선택타석 현황판, 2F/3F/4F 등 층별 타석 그리드, 수량만큼 Multi Select타석현황 목록 (각 타석 상태 포함)선택 수 < 구매 수량인 동안 다음 버튼 disabled
6결제 완료「카드 결제」 화면 후 결제 성공 처리카드결제 성공 실패 후처리결제 성공 시 즉시 타석 이용 시작

#API 명호출 방향사용 시점 / 화면요청 (주요 필드)응답 (주요 필드)비고
A1가맹점 로그인토스프론트 → 엘커넥트키오스크 진입 (도착인증·1회권 공통)가맹점 자격증명 (merchant_id 등)가맹점 토큰 / 세션키오스크는 매장(가맹점) 단위로 인증
A2QR 인증 결과 송신엘커넥트 앱 → 토스 내부 서버03A QR 스캔 직후nonce, 인증 결과, 회원 정보, 시그니처(HMAC-SHA256)OK엔드포인트·인증·필드 사전 합의 필요
A3QR 인증 결과 폴링토스프론트 → 토스 내부 서버03A QR 표출 후 1~2초 간격성공/실패 + 회원 정보TTL 만료 시 거부, 1회 조회 시 세션 무효화. nonce 발급/호출 키오스크 일치 검증
A4얼굴 인증 (사진 전송)토스프론트 → 엘커넥트03B [인증하기] 클릭사진 데이터, 가맹점·단말기 정보성공/실패 + 회원 정보1:N 매칭. 우선 버튼식(자동 인식 X)
A5도착인증 가능 예약 목록토스프론트 → 엘커넥트QR/얼굴 인증 성공 후회원 식별자, 가맹점 정보예약 list (기간제 / 시작·종료 시간)조건 (AND): 오늘 날짜 + 모바일 예약 + 도착인증 필수 옵션 ON + arrival_verified=false
A6도착인증 완료 처리토스프론트 → 엘커넥트05 예약 카드 클릭 → [도착인증하기]예약 ID성공/실패 (arrival_verified = true)처리 후 [홈으로 돌아가기]
B11회권 상품 목록토스프론트 → 엘커넥트1회권 구매 진입 시가맹점 정보상품 list (예: 60분/300분/90분, 가격 포함)키오스크 판매 ON 상품만 응답
B2타석현황 목록토스프론트 → 엘커넥트타석 선택 화면 진입 / 결제 직전가맹점 정보타석 list (층별, 각 타석 상태 포함)점유 충돌 방지 위해 결제 직전에도 재확인 호출
