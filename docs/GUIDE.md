# PDK 사용 가이드 (비개발자용)

코딩을 몰라도 **Claude에게 커맨드를 순서대로 입력**하면 화면설계서를 만들 수 있습니다.
각 단계는 Claude가 질문으로 안내하므로, 답만 하면 됩니다.

---

## 0. 준비

1. 이 레포를 내려받습니다(클론 또는 ZIP 다운로드).
2. 폴더에서 **Claude Code**를 엽니다.
3. (선택) 미리보기 서버: 터미널에서 `python -m http.server 8124` → 브라우저 http://localhost:8124

> 결과는 언제든 `index.html`(또는 화면 파일)을 브라우저로 열어 확인할 수 있습니다.

---

## 1단계 — 프로젝트 시작: `/pdk-init`

```
/pdk-init
```

Claude가 차례로 물어봅니다:
1. **프로젝트 이름**
2. **프로젝트 설명**
3. **디바이스** — 데스크탑 / 모바일 / 토스프론트2 / 반응형(데스크탑·모바일)
4. **PRD 문서**(선택) — `docs/prd/` 에 넣어 둔 HTML 파일명. 지정하면 상단 바에 **"PRD 문서 보기"** 버튼이 생깁니다.
5. **작업 결과를 push할 내 레포 주소** — 없으면 "나중에"라고 답하면 됩니다.

> PDK를 클론해 시작했다면 `origin`이 **PDK 원본 레포**를 가리킵니다. 그대로 두면 내 화면을 push할 때
> 템플릿 레포로 밀게 되므로, `/pdk-init`이 이 연결을 **끊거나 내 레포 주소로 바꿔 줍니다.**
> (커밋 히스토리·파일은 그대로입니다. 나중에 붙이려면 `git remote add origin <주소>`)
> PDK 업데이트는 origin과 무관하게 `/pdk-update`가 알아서 처리합니다.

→ `index.html`과 빈 골격이 생깁니다. 페이지 목록·화면 플로우·Description 패널이 **비어 있는 상태로** 나타납니다.

> 반응형을 고르면 **상단 바 우측에 데스크탑/모바일 토글**이 생깁니다.
> PRD는 나중에 붙여도 됩니다 — `docs/prd/` 에 파일을 넣고 `/pdk-init` 을 다시 실행하면 됩니다.
> 재실행해도 이미 등록한 화면·플로우와 기존 설정은 그대로 유지됩니다.

---

## (선택) 커스텀 디바이스: `/pdk-mockup`

내장 4종 외에 다른 기기 화면을 쓰고 싶을 때:

```
/pdk-mockup my-kiosk ./내목업이미지폴더
/pdk-mockup my-kiosk https://www.figma.com/design/....?node-id=12-34
```

- 이미지가 여러 장이면 Claude가 **고르라고** 물어봅니다.
- **화면 가로×세로(px)** 를 직접 입력합니다.
- 등록 후 `/pdk-init`에서 그 디바이스를 선택할 수 있습니다.

---

## 2단계 — 화면 등록: `/pdk-screen` (유저플로우 순서대로 반복)

화면을 **흐름 순서대로** 하나씩 등록합니다.

```
/pdk-screen 공통 SCR-MAIN-001 메인
/pdk-screen 주문 SCR-LIST-001 상품목록
...
```

각 화면마다 Claude가 물어봅니다:
1. **언제·어떻게 보이는 화면인가요?**
2. **어디서 들어오나요?** (예: 메인에서 "시작하기" 버튼)
3. **다음에 어디로 가나요?** — **분기**도 가능 (예: 결제 성공→완료 / 실패→실패)

→ `pages/` 폴더에 화면 HTML(이름·ID만 표시)이 생기고, **페이지 목록 · 화면 플로우 · Description이 자동으로 그려집니다.**
(`index.html`만 루트에 있고, 나머지 화면은 모두 `pages/` 안에 만들어집니다.)
대화 중 **아직 없는 화면을 언급하면**(예: "결제 실패하면 실패 화면으로") 그 화면도 **즉시 등록되고 HTML까지 만들어집니다.**
이름·카테고리만 물어보고, 그 화면의 다음 이동은 나중에 그 화면 차례에 물어봅니다.

> 화면 ID 권장 형식: `SCR-<카테고리약어>-<3자리>` (예: `SCR-PAY-001`)

이미 등록된 화면의 맥락·이동을 **나중에 채우거나 고칠 때**는 화면 ID만 주면 됩니다.

```
/pdk-screen SCR-PAY-002
```

비어 있는 항목만 물어보고, 이미 적힌 내용과 만들어 둔 화면 HTML은 그대로 둡니다.

---

## 3단계 — 기능 플로우: `/pdk-flow`

등록한 화면들을 **기능 단위 여정**(예: 회원가입, 결제, 도착 인증)으로 묶습니다.

```
/pdk-flow FLW-PAY-001 결제
```

Claude가 물어봅니다:
1. **이 기능은 무엇인가요?** (한 줄)
2. **사용자가 어떤 과정을 거치나요?** (예: 상품 선택 → 결제 → 완료)
3. **어떤 화면들이 순서대로 들어가나요?** — 등록된 화면 목록에서 고릅니다.

→ 좌측 페이지 목록 위에 **플로우 Dock**이 생기고, 플로우를 클릭하면 **그 기능의 화면만** 다이어그램에 보입니다.
여정 순서대로 아직 이어지지 않은 이동이 있으면 **한 번에 확인받고** 연결선을 그어 줍니다.

> 여기서 새 화면이 언급되면 그 자리에서 만들어집니다. 그 화면의 맥락·이동은
> `/pdk-screen <화면ID>` 로 마저 채우세요.
> 한 화면이 여러 플로우에 들어가도 됩니다(예: 메인 화면).

---

## 4단계 — 화면 설계: `/pdk-wireframe`

등록한 화면을 하나씩 설계합니다. 플로우 순서대로 진행하면 흐름이 자연스럽게 맞습니다.

```
/pdk-wireframe SCR-MAIN-001
```

- Claude와 대화하며 화면에 **무엇이 있는지**(버튼·목록·입력칸 등) 정합니다.
- **실제 UI**로 그려집니다 — 버튼에는 버튼 이름, 목록에는 예시 항목이 들어간 **흑백 와이어프레임**입니다.
- **Description이 자동 작성**됩니다.
- Description은 훑어보기용 라벨이라 **한 항목당 한 줄 정도로 짧게** 적힙니다(예: `결제하기 → 결제 진행`).
- 색·이미지 같은 **디자인은 다루지 않습니다**(흑백) — 그건 다음 단계(Figma)에서 입힙니다.
- 우측 Description 항목에 마우스를 올리면 **해당 요소가 강조**됩니다.
- **조건에 따라 화면이 달라지면**(목록 있음/없음, 성공/실패 등) 그렇다고 알려주세요.
  목업 위에 **라디오 버튼**이 생겨 상태를 전환해 볼 수 있습니다.

---

## 5단계 — 디자인 입히기: `/pdk-figma-sync`

Figma 시안을 화면에 입힙니다.

```
/pdk-figma-sync SCR-MAIN-001 https://www.figma.com/design/....?node-id=12-34
```

- Figma에서 디자인을 가져와 와이어프레임에 적용합니다.
- 페이지 목록의 디자인 뱃지가 **"반영"** 으로 바뀝니다.
- Description의 "Figma 링크"가 채워집니다.

> Figma 데스크탑 앱/계정 연결이 필요합니다.

---

## 완성 후

- `index.html` 또는 `pages/` 안의 각 화면 파일을 브라우저로 열어 전체를 확인합니다.
- 좌측 하단 **화면 플로우**에서 노드를 클릭하면 해당 화면으로 이동합니다.
- 좌측 상단 **페이지 목록**에서 행을 클릭해도 이동합니다.
- **화면 플로우·Description 패널**은 헤더를 잡아 옮기고, 네 변·네 모서리를 끌어 크기를 바꿀 수 있습니다.
  바꾼 위치·크기는 브라우저 탭을 닫기 전까지 유지되므로, 화면을 옮겨 다녀도 그대로입니다.

## 체크리스트

- [ ] `/pdk-init`로 프로젝트 생성 (이름·설명·디바이스)
- [ ] (선택) `/pdk-mockup`로 커스텀 디바이스 등록
- [ ] 모든 화면을 `/pdk-screen`으로 유저플로우 순서대로 등록
- [ ] 기능별로 `/pdk-flow`로 여정 정의 (새로 생긴 화면은 `/pdk-screen <화면ID>`로 보강)
- [ ] 화면별 `/pdk-wireframe`로 와이어프레임 UI + Description 작성
- [ ] 화면별 `/pdk-figma-sync`로 디자인 적용
- [ ] `index.html`에서 플로우·목록·Description·디자인 최종 확인

## 자주 막히는 점

| 증상 | 해결 |
|---|---|
| 화면 플로우에 선이 안 그려짐 | 화면을 1개만 등록하면 점만 생깁니다. 이동(다음 화면) 정보를 넣어야 선이 그려집니다. |
| 플로우에 점선 회색 노드 | 화면이 등록되지 않았을 때 나오는 표시입니다. 커맨드로 작업하면 언급한 화면이 바로 만들어지므로 보통 나오지 않습니다 — `config/screens.js`를 직접 손댔다면 그 화면 ID를 `/pdk-screen`으로 등록하세요. |
| Description hover 강조 안 됨 | 그 요소는 `/pdk-wireframe`로 만들어졌는지, target 셀렉터가 있는지 확인하세요. |
| 디자인이 안 보임 | `/pdk-figma-sync`는 Figma 연결이 필요합니다. 노드 지정 URL(node-id 포함)인지 확인하세요. |
