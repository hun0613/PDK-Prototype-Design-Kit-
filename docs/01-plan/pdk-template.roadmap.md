## 0. 한눈에 보기

```
M0 준비 ─ M1 클린업 ─ M2 엔진 일반화 ─┬─ M3 /pdk-init
                                      ├─ M3b /pdk-mockup (커스텀 디바이스)
                                      ├─ M4 /pdk-screen
                                      ├─ M5 /pdk-wireframe
                                      └─ M6 /pdk-figma-sync
                                            └─ M7 문서·예제 ─ M8 검증·배포
```

- **전체 단계**: 10개 마일스톤 (M0~M8, M3b 포함)
- **PDCA 매핑**: M0~M2 = Design 확정·기반 / M3~M7 = Do(구현) / M8 = Check·Report
- **핵심 의존성**: M2(엔진 config 분리 + 디바이스 레지스트리)가 모든 커맨드(M3~M6)의 선행 조건

## M3b. `/pdk-mockup` 커맨드 — 커스텀 디바이스 목업 (FR-11)

| 항목 | 내용 |
|---|---|
| 목표 | 사용자가 자기 디바이스 목업을 등록해 `/pdk-init` 선택지로 사용 |
| 작업 | `/pdk-mockup [디바이스명] [소스경로]` → ① 소스가 이미지 디렉토리면 여러 장 중 **실행 시 선택**, Figma면 MCP 참고 ② **외곽 프레임** 생성 + **캔버스 규격(가로×세로)은 대화로 입력** ③ `config/devices.js` 레지스트리에 등록, 프레임 이미지는 `assets/mockups/<디바이스명>/`에 저장 |
| 완료 기준 | 등록한 커스텀 목업이 `/pdk-init` 디바이스 목록에 뜨고 정상 렌더 |
| 의존성 | M2(레지스트리 구조), 권장 M3 이후 |
| 비고 | 내장 4종과 동일한 스키마로 등록 → 화면들이 동일하게 동작 |

## M4. `/pdk-screen` 커맨드 (FR-03, FR-04)

| 항목 | 내용 |
|---|---|
| 목표 | 화면 등록 → 목록·Description·플로우 자동 갱신 |

| 완료 기준 | 화면 여러 개 순차 등록 시 노드·연결선·분기 자동 작도 |
